# Repository contract

Node Search is a bounded metadata/link-graph prefilter for configured local Markdown roots; README.md owns the product and privacy contract. Preserve the `node_search` public schema and search behaviour unless explicitly authorized. Do not read private vaults for tests or commit derived private metadata. Use synthetic fixtures only.

`.agents/validation.md` owns executable validation and baseline; `.agents/quality.yaml` owns deterministic quality policy; STATE.md owns current readiness. Cache/profile changes require independent review. Local commits do not grant permission to push, publish, restart gateways or modify Hermes core/profile configuration.
